Nadir Network Communication test tools

Tools for checking voice quality, cascading and failover on the local cluster (allocator on port 4100). Open the same room on two devices to talk.

Voice room

Join as host, speaker or listener. Live stats for delay, packet loss and jitter. Camera is optional.

Latency test

Sends beeps through the server and back, and measures how long they take. No microphone needed.

Load test page

Opens many listeners in one browser tab. Driven by the command-line load tester for server capacity runs.

Server stats

JSON: rooms, peers, and CPU per mediasoup worker.
